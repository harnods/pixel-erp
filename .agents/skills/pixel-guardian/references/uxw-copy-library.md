# Pixel Copy Library

> **Scope:** microcopy / UX writing only. NOT a source for components or
> tokens — those come from `DESIGN.md`, `docs/patterns/*`, and the
> `ai.mekari.design` MCP (Pixel 3 Enterprise, Token v2.4). Apply the copy
> *principles*; match each page's actual UI language rather than forcing a
> specific locale.

Mekari's UXW (UX Writing) copy library — bilingual (English / Bahasa Indonesia) reference for terms, template patterns, and fixed patterns used across toasts, captions, badges, call-to-action buttons, and other microcopy. Pulled from the team's Coda/Superhuman Docs copy library v2.1; this is a living document upstream, so re-pull periodically rather than treating this snapshot as permanent.

- **Terms** — short words/phrases with a definitive meaning.
- **Template pattern** — fill-in-the-blank starter text for common scenarios (error messages, empty states, confirmations).
- **Fixed pattern** — complete text for common scenarios; no additional text needed.
